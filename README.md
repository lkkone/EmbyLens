# EmbyLens

多 Emby 服务器监控，沿用 ProxyLens 的 Vue 3 + Python 标准库 + SQLite 和 UI。展示页 `/`，管理后台 `/admin`。

## 本地运行

```sh
npm --prefix frontend ci
./run-local.sh
```

访问 http://localhost:18791 。自动生成的管理账号保存在 `.local/admin.json`。服务数据和 Emby 凭证只保存在 `.local/data/embylens.db`，均不进入版本控制。密码修改时留空保留原密码。数据库含登录所需凭证，备份时应保护文件。

## 数据口径

- 服务器名称支持自定义，留空使用 Emby API 自动获取的名称。副线路固定预留 3 个位置，每条单独填写名称和 HTTPS 地址，留空不启用；原有 CF 线路自动兼容。主、副线路各自验证当前账号及服务器身份。
- 电影数、剧数、单集数仅统计账号可见条目；总数为电影 + 单集，未跨库、跨版本或跨服务器去重。
- 今日新增为 Emby `DateCreated` 处于北京时间当天的电影和单集。服务器可能按文件创建时间生成此字段，不保证是实际上架时间。
- 每分钟探测线路，每 15 分钟更新数量，后台可以手动重新采集。响应耗时含账号验证和服务器信息查询，不能视为播放测速。
- 查询失败保留上次成功统计并展示采集错误及统计时间；首次失败显示 `—`，不会显示虚假零值。
- 最近 5 小时状态条，每格 5 分钟，显示该格最差状态；无数据为灰色。
- 后台可按服务器配置 User-Agent（默认 EmbyLens/0.1.0），用于客户端标识兼容；测试服使用已验证的 Forward 标识。
- CF 防护、禁用 API、账号权限等可能阻止采集。HTTPS 证书正常验证，跨地址重定向不会转发凭证。

## Docker

```sh
cp .env.example .env
# 修改管理账号密码
docker compose up -d --build
```

Docker 数据卷与本地开发数据相互独立。当前项目仅本地运行，未上线。

## 验证

```sh
python3 -m unittest discover -s tests
npm --prefix frontend run build
```

## 安全码与配置导出

在 `.env` 设置 `SECURITY_CODE`，更改后重启服务。本地启动脚本会读取 `.env`，Docker Compose 会传入该变量。查看保存的密码和导出配置都需要管理登录及安全码；5 分钟内错误 5 次会暂时锁定。查看密码 30 秒后隐藏，切换服务器、保存、退出时清除。安全码不会下发给前端。复制内容仅含主路线、两个副路线、用户名和密码，每行 `字段:值`，不加引号；HTTPS 地址未填写端口时显示默认端口 443，校验成功后直接写入剪切板，包含 Emby 密码但不包含安全码或访问令牌。格式是否能自动识别取决于客户端。

## 低干扰接入

新增默认使用 Forward 请求格式，可以按服务器选择已允许的客户端格式。不要求额外确认；客户端允许列表以该服公告为准，界面选项不是所有服务器的通用白名单。403 不再自动轮换标识。既有成功格式与令牌保留。

线路检查间隔至少 5 分钟，带随机错峰；数量约每小时更新。每条线路请求间隔至少 0.5 秒，主备按顺序检测。今日新增最多读取两页、400 个最近条目，超过范围或日期不完整时显示“—”，不将部分数量当成精确值，也不回退扫描整个库。这些是工程默认值，不是服主承诺的安全阈值。

401 在一次令牌续期失败后暂停该线路，保存配置后再试。403 按下一次正常检测重试（约 5 分钟），首次新增或保存修改立即检测，不受旧失败状态限制；429 遵循 Retry-After（含 HTTP 日期）；网络错误逐次延长重试间隔。统计错误至少等待一小时再重试。修改保存会重新安排检测，浏览展示页或管理页只读取本地缓存，不会触发上游请求。不会下载媒体、测速、转码、预加载或修改播放列表/观看记录。采集不是播放保号。
